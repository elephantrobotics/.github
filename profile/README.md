Founded in Shenzhen in 2016, Elephant Robotics develops robots and software for education, research, commercial applications, and everyday life. Our platforms span **robotic arms, mobile robots, humanoid robots, and robotic pets**.

From myCobot, mechArm, and ultraArm to myArm, myBuddy, myAGV, Mercury, and MarsCat, we help people explore what robots can do. Here on GitHub, you'll find SDKs, ROS packages, simulation integrations, and application examples to build with our robots.

## Start building

1. **Find your robot's guide.** Visit our [documentation and support hub](https://www.elephantrobotics.com/en/support-en/) for product manuals, setup instructions, and tutorials.
2. **Prepare your robot.** Follow the guide for your model and controller. Use [myStudio](https://github.com/elephantrobotics/myStudio) for firmware tools and downloads on supported products.
3. **Choose your development tools.** Explore the projects below, and check each repository's supported models, dependencies, and branch instructions.

## SDKs and robot control

- **[pymycobot](https://github.com/elephantrobotics/pymycobot)** — Python APIs and examples for controlling supported Elephant Robotics products.
- **[MyCobotBasic](https://github.com/elephantrobotics/MyCobotBasic)** — Arduino libraries and examples for supported robot controllers.
- **[mycobot_ros2](https://github.com/elephantrobotics/mycobot_ros2)** — ROS 2 packages, robot descriptions, and motion-planning examples for supported robotic arms.
- **[mycobot_ros](https://github.com/elephantrobotics/mycobot_ros)** — ROS 1 packages for robot control, visualization, and MoveIt integration.

## Mobile robots, vision, and simulation

- **myAGV with ROS 2** — Explore the packages for [myAGV](https://github.com/elephantrobotics/myagv_ros2), [myAGV Plus](https://github.com/elephantrobotics/myagv_plus_ros2), and [myAGV Pro](https://github.com/elephantrobotics/agv_pro_ros2) for mobile robot development, mapping, and navigation.
- **[aikit_V2](https://github.com/elephantrobotics/aikit_V2)** — Python and OpenCV examples for vision-guided recognition and pick-and-place applications with supported AI Kits.
- **[mycobot450_isaacsim](https://github.com/elephantrobotics/mycobot450_isaacsim)** — Isaac Sim integration with ROS 2 and MoveIt 2 for myCobot Pro 450.

## Contribute and get help

We welcome bug reports, documentation improvements, examples, and pull requests. Start with the relevant repository's README and contribution guidelines, where available. Licensing varies by project; check the repository and any bundled assets for applicable terms.

For software issues, open an issue in the relevant repository and include your robot model, controller, firmware and software versions, and steps to reproduce the problem. For product setup and technical support, contact [support@elephantrobotics.com](mailto:support@elephantrobotics.com).
